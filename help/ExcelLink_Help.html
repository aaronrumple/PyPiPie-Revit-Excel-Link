Excel Link

Bring Excel worksheets into Revit drafting views and legends with their fonts, colours, borders and fills intact, at true 1:1 print size, and keep them linked so they update when the spreadsheet changes.

Overview

Excel Link reads an .xlsx or .xlsm workbook directly (Excel does not need to be installed) and redraws the chosen range with native Revit elements:

  • Filled regions for cell fills
  • Detail lines for borders, in matching line styles
  • Text notes for cell values, formatted exactly as Excel displays them

Everything for one worksheet is gathered into a single detail group. The group carries the link back to the workbook, so Update Links can redraw it after the spreadsheet is edited, keeping the table wherever you moved it.

Tables are sized to Excel's printed size: a column that prints 1.5" wide in Excel is 1.5" wide on the Revit sheet, whatever the view scale.

Quick start

  1. On the Excel Link tab, click Import Excel.
  2. Click Browse… and choose a workbook. The first sheet appears in the preview.
  3. Click a sheet tab under the preview to view it. Tick the tabs of every sheet you want, or leave them all unticked to import just the one you are viewing.
  4. Choose Drafting view or Legend, check the view name, then click Import.
  5. Each sheet gets its own new view, which opens when the import finishes. Place it on a sheet like any other view.
  6. When the workbook changes, save it in Excel and click Update Links.
A ready-made test workbook is in the extension's samples folder: Excel Link Test Workbook.xlsx. It has one sheet per feature (fonts, number formats, borders, fills, alignment, layout, rich text, formulas) plus a realistic door schedule and finish legend.

Import window

The left side holds the settings; the right side previews the selected worksheet as it will print. Press F1 or click Help to open this page.

Workbook, sheets & tabs

  • Browse… picks the workbook. The last workbook used opens automatically next time.
  • The sheet tabs under the preview work like Excel's. Click a tab to preview it; tick its box to include it in the import.
  • All / None tick or clear every tab. With no tabs ticked, the tab you are viewing is imported. The Import button shows what will happen (Import or Import 3 sheets).
  • With many sheets: scroll the tabs with ◀ ▶, the mouse wheel or the scrollbar; jump to any sheet with ☰; or step with Ctrl+PgUp / Ctrl+PgDn. The counter shows the position (e.g. 4 / 12).
  • Hidden worksheets are not listed.

Range

Each sheet has its own range setting; switching tabs remembers it.

OptionBehaviour
Print area / used range
(default)		Uses the sheet's print area if it has one, otherwise every used cell. Not fixed: when rows or columns are added in Excel, the next update picks them up.
FixedAlways the range typed, e.g. A1:F20. Press Enter or click away to refresh the preview.

Include & line weights

  • Fills, Borders, Text: untick any to leave that part out (e.g. text only).
  • Gridlines: draws Excel's light grey gridlines where a cell has no border and no fill. Off by default, matching Excel's printouts.
  • Hidden rows/columns: includes rows and columns hidden in Excel. Off by default, so they collapse as they do in Excel.
  • Line weights: the Revit pen number used for Excel's thin (and hair), medium and thick borders. Defaults 1 / 3 / 5. Choose the pens that match your template's line weights.

New views

Every imported worksheet gets a new view at a 1:1 (12" = 1'-0") scale, with the table's top-left corner at the view origin.

SettingDetails
Drafting viewChoose the drafting view Type. Click + to create a new drafting view type (it duplicates an existing one). Callout Detail view types are not listed: Revit won't use them for drafting views.
LegendRevit can't create a blank legend through its API, so each new legend is a copy of the legend chosen under From, with its contents removed. The model needs at least one legend (View > Legends > Legend).
NameA pattern using {sheet} (worksheet name) and {workbook} (file name without extension). Default {sheet}. If a view with that name exists, (2), (3)… is added.

The summary box shows the printed size of the range and how many fills, lines and text notes it will create. Warnings appear below it, e.g. fonts that aren't installed or formulas with no saved result.

Updating

  • Excel Link reads the saved workbook. Save in Excel before updating; unsaved edits aren't visible to Revit.
  • Updating rebuilds the table at its current position, even if you moved the group, and keeps it pinned if it was pinned.
  • Change detection: if the file's size and modified time match the last import it is up to date; if not, the file is hashed, so a re-sync that only touches the timestamp (Desktop Connector, OneDrive) doesn't count as a change.
  • Copies of a linked group (copy/paste, duplicated views) each carry the link and update independently.
  • An update is one undo step: Ctrl+Z restores the previous table.
Edits made to the elements inside a linked group (moving text, changing a fill) are replaced on update. Change the workbook instead, or Unlink the table first.

ACC / Autodesk Docs (Desktop Connector)

Workbooks stored in Autodesk Construction Cloud, BIM 360 or Autodesk Docs work through Autodesk Desktop Connector. Browse to the file inside your Desktop Connector folder, normally:

C:\Users\<you>\DC\ACCDocs\<Hub>\<Project>\Project Files\…

Besides the full path, the link stores the location from the connector folder down (e.g. ACCDocs\Hub\Project\Project Files\Schedules\Doors.xlsx). On any computer, Excel Link looks for the workbook in this order:

  1. The saved full path.
  2. The same Desktop Connector location under that user's own DC folder (or a workspace moved elsewhere, e.g. D:\DC).
  3. The path relative to the Revit model.

So links made by one person work for everyone on the project without re-pointing.

If someone's Desktop Connector workspace is outside their user folder, set the Windows environment variable EXCELLINK_DC_ROOT to its location (the folder that contains ACCDocs).

Changes saved by others reach Revit once Desktop Connector has downloaded them to your machine. Reading Excel files directly from the cloud without Desktop Connector is not supported.

What is imported

FeatureSupport
FontsFamily, size, bold, italic, underline, colour. Text is sized so it matches Excel at 1:1 (Revit's Text Size is a font's capital-letter height, so Excel Link converts using each font's own proportions).
Rich text in one cellBold, italic, underline, superscript and subscript per run. Mixed font, size or colour within one cell uses the first run's (a warning lists those cells).
Number formatsDisplayed exactly as Excel shows them: decimals, thousands separators, %, scientific, fractions, currency and accounting, dates, times, elapsed time, conditional sections, [Red]/[Blue] colours, K/M scaling, digits split by text (feet-inches 0"'-"0\", 000-000-0000).
AlignmentLeft/centre/right, top/middle/bottom, indent, wrap, rotation (any angle), vertical stacked text, shrink-to-fit, centre-across-selection, Excel's automatic alignment (text left, numbers right).
BordersAll 13 Excel styles and colours, diagonals, merged-cell borders. Dash patterns are lengthened to Revit's 1/32" minimum. Double borders are two thin lines.
FillsSolid colours including theme colours and tints. Pattern fills and gradients become one blended flat colour.
LayoutColumn widths, row heights, merged cells, hidden rows/columns, print area.
FormulasThe last result saved by Excel is shown. Files saved by other tools may have no results; open and save them in Excel first.

Not imported

  • Conditional formatting colours, data bars and icon sets (only the cell's normal formatting).
  • Strikethrough.
  • Charts, pictures, shapes, comments.
  • Old .xls, .xlsb and .csv files: save as .xlsx.

Small differences to expect

  • Revit can't clip text, so long unwrapped text that Excel cuts off at the next filled cell runs over it in Revit.
  • A wrapped line that only just fits may occasionally break one word differently.
  • Fonts not installed on a computer are substituted by Revit; the import window warns about them.
  • Pure white is drawn as near-white (254, 254, 254). Revit shows exact white as black on a white background; near-white displays and prints as white.

Link data

Each link is stored on its detail group in Revit Extensible Storage (schema ExcelLinkData, GUID 6d3b1f0a-2c8e-4b71-9a55-e1c0b7a4f3d2, public read/write) as a JSON text field:

KeyContents
pathFull path to the workbook
cloudDesktop Connector location, e.g. ACCDocs\Hub\Project\…\file.xlsx
relPath relative to the Revit model
sheet, rangeWorksheet; fixed range or empty for print area / used range
resolved_rangeRange drawn at the last import
opts, weightsInclude options and pen numbers
size, mtime, sha1Change detection
origin, anchor, scalePlacement and the view scale at import
size_pt, imported, vPrinted size, import time, format version

Cell contents are not stored; updates always re-read the workbook. Nothing is written to the workbook.

Troubleshooting

ProblemFix
Status shows File missingThe workbook moved or was renamed. Excel Links > select it > Edit… > Browse…. For ACC files, make sure Desktop Connector has synced the project.
Values are blank or oldThe workbook was saved by a tool that doesn't store formula results, or Excel had unsaved changes. Open it in Excel, save, then update.
Text looks a different widthThe font isn't installed on this computer and Revit substituted another. Install the font or change it in Excel.
Borders too heavy or lightChange the pen numbers (Excel Links > Edit…), or adjust the XL Pen… line styles' weights in Object Styles.
Wrong colours in a highlighted tableHighlights from conditional formatting aren't imported. Apply them as normal cell fills in Excel.
Legend option unavailableThe model has no legend to copy. Create one (View > Legends > Legend), then import.
Drafting type not listedIt is a callout Detail view type. Click + to make a drafting view type instead.
Open Excel doesn't jump to the sheetOn Revit 2025 and later, or without Excel installed, the workbook opens at the sheet it was saved on.
First import is slowRevit is creating new line styles and fill types. Later imports reuse them.

Compatibility

  • Tested: Revit 2024.3 with pyRevit 7.0, IronPython 2.7.12.
  • Expected to work: Revit 2021–2026 with pyRevit 4.8 or later on its IronPython engine. The light/dark window theme needs Revit 2024 or later; older versions use the light theme.
  • Requirements: none beyond Revit and pyRevit. Excel is only needed for Open Excel.
  • Files: .xlsx and .xlsm.

To remove Excel Link, delete the ExcelLink.extension folder from %APPDATA%\pyRevit\Extensions and reload pyRevit. Existing tables stay in your models as ordinary detail groups.
